# gh-setup: seed GitHub planning for Tachocline Industries

Scripts that write **only** to `howardisaacson/tachocline-industries`, plus one user-level Project linked only to it. `REPO` is hardcoded, every `gh` call names the repo or owner explicitly, and the scripts abort if `issues.json` or the logged-in user don't match. They are safe to re-run because they only create what's missing.

| File | Purpose |
|---|---|
| `issues.json` | The plan: 18 labels, 6 milestones (one per phase), 58 issues (29 linked as sub-issues). Generated by `build_plan.py`. |
| `build_plan.py` | Source of the plan. Edit, then `TI_REPO=/path/to/clone python3 build_plan.py` |
| `setup_labels_milestones_issues.sh` | Labels → milestones → issues → sub-issue links |
| `setup_project.sh` | Project, link to repo, Phase/Priority/Size fields, add all issues, set Phase, try to create views |

## Run order (on the Mac)
1. **Push the repo update first** (update-3: ADR 0018, `docs/github-workflow.md`, `.github/` templates). The issue bodies link to those files on `main`.
2. `gh auth status` should show you logged in as **howardisaacson**.
3. `./setup_labels_milestones_issues.sh` (needs scope `repo`)
4. `gh auth refresh -s project`, then `./setup_project.sh`
5. Finish the web-UI checklist below.

## Web-UI checklist (what the CLI/API can't fully do)
The API (GraphQL `createProjectV2View`, added July 2026) can create views. The script tries to create Board, Table and Roadmap, but view layout settings and workflows are UI-only:
- [ ] **Board:** group by *Status* (Todo / In Progress / Done)
- [ ] **Table:** show Status, Phase, Priority, Size, Labels, Milestone, Linked pull requests; group by *Phase*
- [ ] **Roadmap:** set the date field(s), e.g. add *Start date*/*Target date* fields or use Milestone; zoom to Quarter
- [ ] If the API couldn't create a view, create it manually: **+ New view** → Board / Table / Roadmap
- [ ] **Workflows** (Project ⋯ → Workflows):
  - [ ] *Item added to project* → Status: Todo
  - [ ] *Item closed* → Done
  - [ ] *Pull request merged* → Done
  - [ ] *Auto-add to project*: filter `is:issue,pr` on `howardisaacson/tachocline-industries`
  - [ ] *Auto-archive* (optional)
- [ ] Set **Priority** and **Size** on Phase 0 and Phase 1 issues (deliberately left for you, as triage practice)
- [ ] Repo **Settings → General → Features:** confirm Issues and Projects are enabled
- [ ] Repo **Settings → Rules/Branches:** protect `main` (that's issue "Protect main and enable secret scanning")
- [ ] Delete the default "View 1" if it's redundant
